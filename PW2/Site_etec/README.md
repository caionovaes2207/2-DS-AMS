#  Site Etec Zona Leste

Projeto desenvolvido com HTML, CSS e PHP com o objetivo de apresentar informações institucionais da Etec Zona Leste, seus cursos e formas de contato.

---

##  Objetivo do Projeto

Criar um site informativo contendo:
- Página inicial institucional
- Página de cursos
- Página de gestão
- Página de contato com formulário funcional em PHP

---

##  Página Inicial (Home)

📌 **Objetivo:**  
Apresentar a escola, destacar seus diferenciais e direcionar o usuário para outras páginas do site.
